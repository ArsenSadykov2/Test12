# Recipe App 🍳

Full-stack web application for creating and managing recipes.

## Stack
**Frontend:** React, TypeScript, Redux, Material UI, Vite  
**Backend:** Node.js, Express.js, MongoDB, TypeScript  
**Auth:** Google OAuth  
**Other:** Multer (image upload), Axios  

## Features
- Google OAuth authentication
- Create, view and manage recipes
- Image upload for recipes
- Responsive UI with Material UI

## Running locally

### Backend
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
